# SCAMPER

<aside>
💡

새로운 아이디어를 도출하거나 기존 제품, 서비스를 개선할 때 사용하는 창의적 발상 프레임워크.

</aside>

- Substitute (대체): 다른 재료, 사람, 프로세스로 바꿀 수 있는가?
- Combine (결합): 두 가지 이상의 기능이나 아이디어를 합칠 수 있는가?
- Adapt (적응/응용): 다른 분야의 방식을 가져와 적용할 수 있는가?
- Modify / Magnify (수정/확대): 모양, 색상, 크기를 변경하거나 극대화할 수 있는가?
- Put to another use (다른 용도): 전혀 다른 목적으로 사용할 수 있는가?
- Eliminate (제거): 불필요한 요소나 단계를 없앨 수 있는가?
- Reverse / Rearrange (반전/재배치): 순서를 바꾸거나 역발상을 할 수 있는가?
